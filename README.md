# Luis y Gloria (luisp193.github.io)

Web publicada con GitHub Pages en https://luisp193.github.io/

- La web está en la carpeta `web/` (página única `index.html` e imágenes en `web/img/`).
- Cada cambio que se sube a `main` se publica solo (`.github/workflows/publicar.yml`).
- El botón de descarga apunta a la última versión publicada del Simulador Foto
  (`luisp193/FOTOGRAFIA`, Releases), así que no hay que tocar la web al actualizar la app.
